## About
This an e-commerce project built as a distributed system of a book store. I started this project to learn more about microservices and distributed systems.

To access more information about the project, including how to run it yourself check out this [document](https://github.com/inkwell-store/inkwell-store/blob/main/README.md).

## Technologies
The system is built with:
* Angular
* Spring
* RabbitMQ
* PostgreSQL
* Docker containers and Docker Compose
